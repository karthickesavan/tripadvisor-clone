Tripadvisor UI Clone

A frontend Tripadvisor homepage UI clone built using HTML and CSS. This project recreates the visual structure and layout of the Tripadvisor travel website for learning and frontend development practice.

Features
Tripadvisor-style navigation bar
"Plan with AI" button
Search section with:
Search All
Things to Do
Hotels
Restaurants
Rounded search bar with Ask AI and Search buttons
Bright green promotional section
Travel experience categories
Interest cards:
Outdoors
Food
Culture
Water
Travel guide promotional banner
New Delhi experience cards
Hotel/experience cards
Iconic destination cards
The Wanderer promotional section
Travellers' Choice Awards section
Multi-column footer
Responsive design for desktop, tablet, and mobile
Technologies Used
HTML5
CSS3
Google Fonts
Font Awesome Icons

No JavaScript or frontend frameworks are used.
Design

The project focuses on recreating the visual experience of the Tripadvisor homepage, including:

Dark green typography
Bright green promotional sections
Rounded search components
Travel cards
Destination imagery
Responsive layouts
Clean spacing and typography
Responsive Design

The website is designed to adapt to:

Desktop
Laptop
Tablet
Mobile

CSS media queries are included to adjust navigation, cards, grids, promotional sections, and the footer for smaller screens.
